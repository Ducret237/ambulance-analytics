14. Definition of Done (DoD)

Une fonctionnalité d'Ambulance Analytics sera considérée comme terminée lorsque :
- Tous ses critères d'acceptation sont satisfaits.
- Les cas nominaux et les cas d'erreur pertinents sont testés.
- Le code est lisible et correctement organisé.
- Aucun secret ou renseignement personnel n'est publié.
- Le code a fait l'objet d'une relecture.
- Les tests existants continuent de réussir.
- La documentation nécessaire est mise à jour.
- Les modifications sont intégrées dans main.
- L'Issue GitHub correspondante est clôturée.
